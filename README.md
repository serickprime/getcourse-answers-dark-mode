# GetCourse Answers Dark Mode

Тёмная графитовая тема для страницы проверки домашних заданий в GetCourse.

Расширение работает в Google Chrome и меняет оформление только на страницах:

`https://university.zerocoder.ru/teach/control/answers`

Поддерживаются вложенные адреса с фильтрами, сортировкой и номерами страниц. Другие разделы GetCourse и сайты не затрагиваются.

## Возможности

- Графитовые фон, панели, комментарии, поля ввода, фильтры и боковое меню.
- Более читаемый системный шрифт Segoe UI на Windows без изменения размеров текста.
- Тёмное оформление блоков файлов и панели HW Checker, без изменения содержимого прикреплённых документов и изображений.
- Скрытие рекламного баннера в рабочем разделе при включённой тёмной теме.
- Переключатель «Тёмная тема» в значке расширения. По умолчанию включена. Настройка сохраняется после закрытия браузера.
- Изменения применяются сразу, без перезагрузки страницы.

## Установка в Chrome

Никакие программы для разработки устанавливать не нужно.

1. На странице этого репозитория нажмите **Code**, затем **Download ZIP**.
2. Распакуйте архив в постоянную папку на компьютере. Не удаляйте и не перемещайте её после установки.
3. Откройте в Chrome адрес `chrome://extensions`.
4. Включите **Режим разработчика** в правом верхнем углу.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите распакованную папку **getcourse-answers-dark-mode-main**, в которой непосредственно находится файл `manifest.json`.
7. Откройте страницу проверки заданий GetCourse. Тёмная тема включится автоматически.

Если ранее устанавливалась тестовая копия этого расширения, сначала отключите её на странице `chrome://extensions`, чтобы две копии не действовали одновременно.

## Использование

Откройте нужную страницу проверки заданий. Для отключения или включения оформления нажмите значок расширений Chrome (значок пазла), выберите **GetCourse Answers Dark Mode** и переключите **Тёмную тему**.

В выключенном состоянии остаётся исходное оформление сайта. Выбранное значение сохраняется.

## Обновление

1. Скачайте свежий ZIP из этого репозитория.
2. Распакуйте содержимое поверх файлов в папке, из которой расширение уже загружено в Chrome. Не изменяйте расположение папки.
3. Откройте `chrome://extensions` и нажмите **Обновить** или кнопку перезагрузки на карточке расширения.
4. Обновите вкладку GetCourse.

## Если тема не включается

- Убедитесь, что открыт адрес, начинающийся с `https://university.zerocoder.ru/teach/control/answers`.
- Убедитесь, что расширение включено в `chrome://extensions` и переключатель «Тёмная тема» активен.
- Если после обновления сохранились прежние стили, перезагрузите расширение и вкладку.
- Для работы требуется **Google Chrome 120 или новее**.

## Конфиденциальность

Расширение работает локально. Оно не отправляет ответы учеников, файлы или личные данные на внешний сервер. Для сохранения переключателя используется стандартное разрешение Chrome `storage`. Сервер, регистрация и платные сервисы не нужны.

## Состав репозитория
